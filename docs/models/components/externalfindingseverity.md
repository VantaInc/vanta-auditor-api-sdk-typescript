# ExternalFindingSeverity

ExternalFindingSeverity describes the severity of an external finding (Vulnerability or Security Alert)

## Example Usage

```typescript
import { ExternalFindingSeverity } from "vanta-auditor-api-sdk/models/components";

let value: ExternalFindingSeverity = "CRITICAL";
```

## Values

```typescript
"CRITICAL" | "HIGH" | "LOW" | "MEDIUM"
```
