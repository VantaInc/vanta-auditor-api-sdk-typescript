# OwnerAssignment

Resource owner (user or team) assigned to this information request.
Returns null if no resource owner is assigned.


## Supported Types

### `components.One`

```typescript
const value: components.One = {
  displayName: "Jerrell_Homenick74",
  id: "<id>",
  type: "user",
};
```

### `components.Two`

```typescript
const value: components.Two = {
  displayName: "Noel74",
  id: "<id>",
  type: "team",
};
```
