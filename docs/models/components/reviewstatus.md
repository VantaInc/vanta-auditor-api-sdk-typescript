# ReviewStatus

Review status of the risk scenario, or null if not set.

## Example Usage

```typescript
import { ReviewStatus } from "vanta-auditor-api-sdk/models/components";

let value: ReviewStatus = "APPROVED";
```

## Values

```typescript
"APPROVED" | "DRAFT" | "NOT_REVIEWED" | "AWAITING_SUBMISSION" | "PENDING_APPROVAL" | "REQUESTED_CHANGES"
```
