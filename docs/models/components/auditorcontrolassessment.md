# AuditorControlAssessment

A control's auditor assessment returned by the assessment write endpoint.

## Example Usage

```typescript
import { AuditorControlAssessment } from "vanta-auditor-api-sdk/models/components";

let value: AuditorControlAssessment = {
  controlId: "<id>",
  segmentId: "<id>",
  assessmentState: "IN_PLACE",
  justification: "<value>",
};
```
