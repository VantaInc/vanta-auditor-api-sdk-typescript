# UpsertAuditControlAssessmentInput

Input for upserting a control's auditor assessment within an audit. Overwrites
the assessment for this control in the chosen program segment.

## Example Usage

```typescript
import { UpsertAuditControlAssessmentInput } from "vanta-auditor-api-sdk/models/components";

let value: UpsertAuditControlAssessmentInput = {
  assessmentState: "MINOR_NON_CONFORMITY",
  justification: "<value>",
  auditorEmail: "<value>",
};
```
